# FitzQuake
Amiga 68k port of FitzQuake using my own AmiQuake SDL port as a base.

https://www.kristianduske.com/fitzquake/

This port was done to test the functionality of my NovaMesa OpenGL library (and it passed with flying colors!).

PiStorm is currently much too slow to run this kind of game on a single CPU thread, Mesa is only practical when used with a multi-core CPU.
